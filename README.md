# Астродействия

Информационный сайт проекта. Статические страницы на HTML и CSS.

- `index.html` — услуги, цены, реквизиты и контакты.
- `privacy.html` и `terms.html` — правовые документы.
- `style.css` — оформление и адаптация под мобильные устройства.

Реквизиты и адреса MAX обновляются в `index.html`. Оплата и пользовательские данные в этом репозитории не хранятся.
